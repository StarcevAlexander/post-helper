# Разбор Instagram мастера браузерным агентом

Мастер в приложении нажимает «Разобрать по ссылке» и даёт согласие. Заказ встаёт в очередь на сервере. Агент на вашем компьютере берёт заказ, смотрит публичный профиль в браузере, собирает данные и скриншоты и отправляет их на сервер. Сервер делает разбор через Claude и кладёт его в профиль мастера.

Очередь живёт на сервере. Письмо на почту может только разбудить вас, но не заменяет очередь: у письма нет состояния, повторов и проверки доступа.

## Подготовка

1. На сервере задайте `AGENT_TOKEN` (от 24 символов). Без него маршруты агента выключены.
2. Создайте `tools/agent/.env`:

```
AGENT_SERVER=https://адрес-сервера
AGENT_TOKEN=тот же токен
```

Файл `.env` не попадает в git.

## Правила безопасности

- Берём только профили из очереди, ничего другого.
- Заходим своим браузером, лучше отдельным вторым аккаунтом. Лайки, подписки, сообщения, комментарии запрещены.
- Между заказами пауза не меньше двух минут. Не больше 10 заказов в день.
- Вход потребовал пароль, капча, «действие заблокировано», профиль закрытый или не найден: сразу `fail` и остановка. Обходить нельзя.
- Instagram может ограничить аккаунт за автоматический просмотр. Риск несёте вы, это нарушение правил сервиса.

## Порядок

1. `node tools/agent/ig-agent.mjs next` печатает заказ: `id`, `handle`, профиль мастера. Код 3 значит, что очередь пуста.
2. Откройте `https://www.instagram.com/<handle>/` и соберите:
   - шапку: имя, описание, число подписчиков и подписок, актуальное;
   - сетку публикаций: 2–3 скриншота при прокрутке;
   - до 3 последних публикаций: подпись, лайки, комментарии, дата, ссылка;
   - вкладку Reels, если есть.
3. Скриншоты сложите в папку (до 12 картинок, каждая до 6 МБ, jpeg/png/webp/gif).
4. Запишите `data.json`:

```json
{
  "handle": "anna_nails",
  "name": "Анна",
  "bio": "Маникюр, Москва",
  "followers": 1250,
  "following": 340,
  "highlights": ["Работы", "Отзывы"],
  "posts": [
    { "type": "reel", "caption": "Нюд", "likes": 12, "comments": 0, "views": 480, "date": "2026-10-12", "url": "https://www.instagram.com/p/…" }
  ]
}
```

   Неизвестное поле не выдумывайте: пропустите или поставьте `null`.
5. `node tools/agent/ig-agent.mjs submit <id> --data data.json --images папка-со-скринами`
6. Если собрать нельзя: `node tools/agent/ig-agent.mjs fail <id> "причина"`. Для закрытого или несуществующего профиля добавьте `--final`, чтобы заказ не повторялся.

Коды выхода: 2 неверный вызов, 3 очередь пуста, 4 сервер недоступен, 5 токен не подошёл, 6 сервер отказал.

## Как компьютер узнаёт о заказе

Сервер сам до вашего компьютера достучаться не может. Компьютер узнаёт о заказах, только спрашивая сервер. Это делает сторож `tools/agent/watch.mjs`: раз в 2 минуты спрашивает очередь, при заказе запускает Claude Code с Chrome по этой инструкции. Между заказами пауза 2,5 минуты, в сутки не больше 10 заказов. Ключи: `--once` (одна проверка), `--dry` (без запуска Claude), `--interval`, `--max-per-day`.

Автозапуск сторожа даёт автономному агенту доступ к вашему браузеру без вас, поэтому его включают осознанно и сами: в Планировщике заданий Windows, «при входе в систему». Автоматически я его не запускаю и боевую проверку сторожа не делал, система запретила такой запуск без вашего решения.
