# Контент-план по заявке мастера

Мастер в приложении указывает ссылки на свои соцсети, не менее пяти (и сколько угодно ещё) ссылок на страницы-референсы, отмечает цели и пишет пожелания и рекомендации. Заявка попадает в базу, и её подхватывает сторож заявок (`intake-agent.md`); посмотреть заявки можно командой `intakes`. Дальше вы работаете на своём ПК и заливаете результат в приложение мастера.

## Порядок

1. Прочитать заявку: `node tools/owner/owner.mjs intakes` (новые) или `intakes ready` (закрытые).
2. Изучить соцсети мастера, познакомиться с ним и разобрать референсы из заявки.
3. Составить `plan.json` (формат ниже) и залить: `node tools/owner/owner.mjs plan <id мастера> plan.json`. Заявка станет «готова», у мастера откроется экран «План готов» с вашей запиской.
4. Залить референсы к публикациям: `node tools/owner/owner.mjs refs <id мастера> <id публикации> файл1 файл2 файл3 --captions "подпись 1|подпись 2|подпись 3"`. Форматы: png, jpg, webp, mp4, webm, до 3 файлов и 6 МБ каждый.

Всё это делает команда `/content-plan` в Claude Code. Без вашего участия то же делает сторож заявок, см. `intake-agent.md`.

Через месяц, когда календарь закончился, итоги и новый план делает `/content-review` (см. `content-review.md`).

Чтобы стереть референсы мастера целиком по всем публикациям: `node tools/owner/owner.mjs refs-clear <id мастера>`. Повторная заливка к одной публикации и так заменяет её прежние файлы.

## Пожелания и рекомендации

Это свободный текст мастера. План обязан их учитывать: рубрики, форматы, идеи и расписание сверяются с каждым пунктом. В `note` плана напишите мастеру, что учтено. Если пожелание невыполнимо, объясните причину там же.

## Референсы

Это страницы, чей контент и стиль подачи мастер хочет взять за образец или переработать (рерайт) под себя. В форме для них пять готовых полей, можно добавить ещё (на сервере предел 100 ссылок). Поля необязательные, часть может остаться пустой. В Telegram и в `intakes` они идут отдельным блоком «Референсы». Разбирайте их так же, как страницы мастера: рубрики, форматы, ритм, подача. Дословно не копируйте, тексты и кадры перерабатывайте под голос и нишу мастера. В `note` плана напишите, что взято у референсов.

## Формат plan.json

Нужен хотя бы один из блоков `strategy`, `calendar`, `kits`. Повторная заливка заменяет блоки, которые вы прислали, остальные данные мастера не трогает. Отметки «опубликовано» у публикаций с тем же `id` сохраняются.

```json
{
  "note": "Записка мастеру: что учтено из пожеланий",
  "strategy": {
    "summary": "...",
    "positioning": "...",
    "profileFixes": ["..."],
    "pillars": [{ "title": "...", "description": "...", "ideas": ["..."] }],
    "cadence": { "reels": 2, "posts": 1, "stories": 4, "note": "..." },
    "firstSteps": ["..."]
  },
  "calendar": {
    "startedOn": "2026-10-23",
    "schedule": { "slots": [{ "weekday": 1, "time": "11:00" }], "publishTime": "19:00" },
    "items": [
      { "id": "w1-mon", "date": "2026-10-26", "time": "19:00", "format": "reels", "pillar": "...", "idea": "...", "done": false }
    ]
  },
  "kits": {
    "w1-mon": {
      "shots": ["..."],
      "frames": [{ "visual": "...", "overlay": "..." }],
      "caption": "...",
      "hashtags": ["#..."],
      "tip": "..."
    }
  }
}
```

- `weekday`: 0 это понедельник, 6 это воскресенье (как в календаре приложения).
- `format`: `reels`, `post` или `stories`.
- `date` в формате ГГГГ-ММ-ДД, `time` в формате ЧЧ:ММ.
- `kits` привязываются к публикациям календаря по `id`. Комплект без такой публикации сервер отклонит.
- Календарь: 4 недели от `startedOn`, до 120 публикаций.

## Настройка уведомлений

Сервером управляют с локального ПК, поэтому Telegram выключен: строки `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `server/.env` закомментированы. Заявки видны командой `intakes`, а сторож заявок сам составляет план и пишет отчёт в `tools/intake-agent/reports`. Чтобы вернуть сообщения в Telegram, уберите решётки перед обеими строками и перезапустите сервер: переменные нужны вместе, с одной сервер стартует с предупреждением и уведомления остаются выключенными.

## Знакомство в чате

Вопросов знакомства в чате у нового мастера нет: он знакомится с вами через ссылки на соцсети, чат обычный. Кнопки знакомства в настройках тоже нет. У тех, кто уже отвечал на вопросы или имеет стратегию, всё остаётся как было.
